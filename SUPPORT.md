# Support for this fork

Use RSI project Issue tracker for fork bugs, migration blockers and feature requests. Programme Issue #4369 links conversion work. Include affected command, expected/actual behavior, reproduction fixture and source SHA.

[Migration plan](docs/migration/README.md) describes current support boundaries. [AGENTS.md](AGENTS.md) and [CONTRIBUTING.md](CONTRIBUTING.md) govern development.

Toolkit's inherited AWS reference material remains useful product documentation. It does not represent an AWS support or contribution arrangement for this fork. AWS service incidents use existing AWS support channels. Keep vulnerability details private and use the relevant vendor's private process for upstream issues; never include secrets in Issues.
